# austin-chat-archive (was cityanatomyservices.github.io)

**Archived 2026-09-09.** This repo held austin.chat, a family of geofence-based
ephemeral chat maps for Austin, TX. The concept was shelved on 2026-09-02
(it needs a large user base to work) and the repo was renamed on 2026-09-09
so that `cityanatomyservices.github.io` could serve the City Anatomy site
(anatomy.city) instead. GitHub Pages is disabled here; austin.chat no longer
resolves to a site.

The reusable asset is `data/` — 1,202 curated Austin geofences (OSM lineage,
ODbL). They were imported into the local GIS library as
`C:\GISData\austin\places.gpkg` on 2026-09-02.

The daily-feed and event-scrape Actions stop with the archive.
